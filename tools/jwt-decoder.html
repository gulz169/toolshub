Paste a JWT. The header and payload are decoded here. The signature is not verified.

About this tool

Decode a JSON Web Token to read its header and payload, including expiry time. The token stays in your browser.

Frequently asked questions

Does decoding verify the token?

No. Decoding only reads the contents. Verifying the signature needs the secret or public key.

Is it safe to paste my token?

The tool runs locally and does not send it anywhere, but avoid sharing live production tokens with others.

What is in a JWT?

Three parts separated by dots: header, payload and signature.
