Frequently asked questions

What is a hash?

A hash is a fixed-length fingerprint of data. The same input always gives the same hash, and a tiny change gives a very different one.

Can a hash be reversed?

No. Hashing is one-way, so you cannot get the original text back from the hash.

Which algorithm is safest?

SHA-256 or stronger is recommended. SHA-1 is only for old compatibility and should not be used for security.
