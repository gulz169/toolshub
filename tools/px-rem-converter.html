Frequently asked questions

What is rem?

rem is a CSS unit relative to the root font size, usually 16px, so 1rem equals 16px by default.

Rem or px, which is better?

rem respects user font-size settings, which helps accessibility. px is fixed.

Can I change the base size?

Yes. Enter your own base font size if your site does not use 16px.
