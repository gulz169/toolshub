Frequently asked questions

What details does it show?

It shows width and height in pixels, file size, file type and related information from the file.

Why do forms ask for image size in KB?

Many portals limit file size. Check your size here, then use the compressor if it is too large.

Is my image uploaded?

No. It is read on your device only.
