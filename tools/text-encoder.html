Frequently asked questions

How is text turned into binary?

Each character is converted to its code and shown as a series of 0s and 1s.

Does Morse code support Urdu?

Standard Morse is for English letters and numbers, so Urdu text is not supported.

Can I decode back?

Yes. Paste the encoded text and choose decode to get the original text.
