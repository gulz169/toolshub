About this tool

Frequently asked questions

How do I find an error in my JSON?

Paste it in and the tool shows what is wrong, such as a missing comma, quote or bracket.

What is the difference between format and minify?

Format adds indentation so it is easy to read. Minify removes spaces to make it smaller.

Is my JSON sent anywhere?

No. It is processed in your browser, so it is safe for private data.
