About this tool

Split a restaurant or group bill between friends, with optional tip and tax. See how much each person pays in seconds.

Frequently asked questions

How do I add a tip?

Enter the tip percentage and it is added to the bill before dividing by the number of people.

Does it work with any currency?

Yes. It only does the math, so you can use rupees, riyals, dollars or anything else.

Can I split unevenly?

This tool divides equally. For uneven shares, calculate each person's own items separately and add the shared costs.
