Frequently asked questions

What is the difference between HEX, RGB and HSL?

They are three ways to write the same color. HEX is a short code like #ff0000, RGB gives red, green and blue values, and HSL uses hue, saturation and lightness.

Can I type a code instead of picking?

Yes. Paste a HEX, RGB or HSL value and the other formats update.

Which format should I use on websites?

All three work in CSS. HEX is the most common, while HSL is easier when you want lighter or darker shades.
