About this tool

See the page count, page size, file size and basic details of any PDF without opening a heavy app.

Frequently asked questions

What details are shown?

Page count, page dimensions, file size and document properties such as title and author when present.

Does it work on password-protected PDFs?

Protected files may not open. Remove the protection first with the original password.

Is my PDF uploaded?

No. It is read in your browser.
