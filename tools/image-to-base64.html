About this tool

Convert an image into a Base64 string or data URI to embed it directly in HTML, CSS or JSON.

Frequently asked questions

When should I use Base64 images?

Use it for very small images or icons you want inside the code. Large images get bigger and are better as normal files.

How do I use the result in HTML?

Paste the data URI in the src of an img tag.

Is my image uploaded?

No. Conversion happens in your browser.
