About this tool

Encode text to Base64 or decode a Base64 string back to readable text. Handles Urdu and other Unicode characters correctly.

Frequently asked questions

What is Base64?

Base64 is a way to represent data using only letters, numbers and a few symbols so it can travel safely in emails, URLs and JSON.

Is Base64 encryption?

No. Anyone can decode it, so never use it to hide passwords or private data.

Why do I get an error when decoding?

The input is probably not valid Base64, or it has missing characters or extra spaces. Copy the full string again.
