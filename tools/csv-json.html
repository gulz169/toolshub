About this tool

Convert CSV data to JSON or JSON back to CSV in one click. Handy for developers, spreadsheets and data cleaning.

Frequently asked questions

Does the first row have to be a header?

For CSV to JSON, the first row is used as the field names so each row becomes an object.

Can I convert an Excel file?

Save or export the sheet as CSV first, then paste the CSV text here.

Is my data uploaded?

No. Conversion runs in your browser and nothing leaves your device.
