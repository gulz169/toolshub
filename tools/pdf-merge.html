How to use

  1. Add two or more PDF files.
  2. Use the arrows to set the order.
  3. Press Merge and the combined PDF downloads.

Your files never leave your device.

About this tool

Join several PDF files into one document. Drag to set the order and download a single merged PDF.

Frequently asked questions

Can I change the order before merging?

Yes. Drag the files into the order you want, then merge.

Is there a limit on files?

There is no set limit, but many large files can be slow on a phone.

Are my PDFs uploaded?

No. They are merged in your browser and stay on your device.
