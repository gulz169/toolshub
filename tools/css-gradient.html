Frequently asked questions

How do I use the gradient on my site?

Copy the generated background rule and paste it into the CSS of any element.

What is the difference between linear and radial?

Linear gradients blend colors along a straight line. Radial gradients spread outward from a center point.

Can I add more than two colors?

Yes. Add extra color stops to create multi-color gradients.
