About this tool

Encode special characters into HTML entities or decode entities back to normal text. Prevents broken markup when showing code on a page.

Frequently asked questions

What is an HTML entity?

It is a safe way to write characters like <, > and & in HTML, for example &lt; for the less-than sign.

When should I encode text?

Encode when you want to display code or special characters as text instead of letting the browser treat them as HTML.

Does it help with security?

Escaping user input is one part of preventing XSS, but real sites should also escape on the server side.
