How to use

  1. Type the value and pick a barcode type.
  2. Download the image.

EAN-13 needs 12 or 13 digits, EAN-8 needs 7 or 8, UPC needs 11 or 12. Nothing you enter leaves your device.

About this tool

Create barcodes such as Code 128, EAN-13 and UPC from any text or number and download them as an image. Useful for shop products, inventory and labels.

Frequently asked questions

Which barcode type should I choose?

Code 128 works for most text and numbers. EAN-13 and UPC are for retail products and need a fixed number of digits.

Can I print the barcode?

Yes. Download the image and print it at a good size. Keep enough white space around it so scanners can read it.

Does it work offline?

Yes, once the page has loaded it generates barcodes in your browser without sending data anywhere.
